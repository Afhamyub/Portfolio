# Afham Ayub — Portfolio

A motion-led personal portfolio for **Afham Ayub**, a BS Computer Science student at FAST University in Lahore.

## Live site

[afhamyub.github.io/Portfolio](https://afhamyub.github.io/Portfolio/)

## About

This portfolio brings together my interests in creative development, game logic, agentic AI, automation, and sketching. It includes interactive studies inspired by projects such as my chess game and Candy Crush prototype.

## Highlights

- Custom damped scrolling and scroll-linked animation
- Opposing vertical image rails
- Animated About portal
- Interactive knight-movement study
- Horizontally scrolling selected-work gallery
- Responsive desktop, tablet, and mobile layouts
- Keyboard-friendly controls and reduced-motion support
- Grain, halftone, and monochrome editorial art direction

## Built with

- Semantic HTML
- CSS
- Vanilla JavaScript
- Anime.js
- Local display fonts and image assets

No React, Tailwind, GSAP, Lenis, or build step is required.

## Run locally

Serve the repository root with any static server. For example:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.
